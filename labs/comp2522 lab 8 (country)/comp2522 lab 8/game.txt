CLI game that picks a random country name from a
text file and has the player guess it

Classes: 
- ca.bcit.comp2622.lab8.countrygame.WordList (load countries)
- ca.bcit.comp2622.lab8.countrygame.HighScoreService (read/write best)
- ca.bcit.comp2622.lab8.countrygame.LoggerService (open/write session log)
- Game (loop and rules)

After each guess:
- Wrong length (X). Need Y.
or
- N letter(s) correct (right position)
or
- Correct!

States:
- track attempts
- save best (fewest) attempts to a high-score file
- log each session's guesses
